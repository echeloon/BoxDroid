This directory keeps only the written reports. The raw captures they cite
(simpleperf reports, generated-code dumps, disassembly, per-run JSON/CSV,
device property snapshots and plots) were moved out of the repository to keep
clones small.

The full set of 1,513 files is published as a release asset:

- `native-perf-resume-20261014-raw.tar.gz`
- SHA-256 `f21f659c38f60cb5c2a391c7973dbafab22ea505cae93d7fb4d48a7d17ddced2`

Extract it from the repository root to restore the original paths:

```bash
tar -xzf native-perf-resume-20261014-raw.tar.gz
```
