# App-local Vulkan loader provenance

- libadrenotools: https://github.com/bylaws/libadrenotools, revision
  `8fae8ce254dfc1344527e05301e43f37dea2df80`.
- liblinkernsbypass: https://github.com/bylaws/liblinkernsbypass, submodule revision
  `aa3975893d83ef1bc84c321ec60c65fbf1287887` (repository identified in
  libadrenotools' pinned `.gitmodules`).

Both components use BSD-2-Clause. Their complete LICENSE files and source
copyright/SPDX notices are retained. The same complete notices are packaged
in every APK under `assets/third-party-notices/`, to accompany binary
redistribution.

The retained `src/hook/kgsl.h` is a Linux userspace API header marked
`GPL-2.0 WITH Linux-syscall-note`, with Linux Foundation and Qualcomm copyright
notices preserved. Its full GPL-2.0 license and syscall exception are supplied
in `android/app/src/main/assets/third-party-notices/kgsl-uapi.txt` alongside
the BSD notices. The syscall exception permits including these API declarations
in userspace applications; no kernel implementation is vendored.

Only the Android driver-loading library, namespace dependency, headers,
runtime hooks, build inputs, README files, and licenses are retained. Upstream
ROM/driver tooling, QTI mapper shims, BCn patching and its generated byte array,
assembly regeneration script, and standalone installation template are omitted.
The only change to retained upstream source is `libadrenotools/CMakeLists.txt`:
it excludes the unused BCn translation unit and standalone installation rules.
Loader and hook implementations are otherwise unchanged at the pinned revisions.

No GPU driver ZIP or binary is bundled. BoxDroid imports compatible packages
selected by the user through Android SAF into app-private storage.
